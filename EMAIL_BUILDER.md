# Email Template Builder Documentation

## Overview
The Email Template Builder is a visual design tool that allows writers to create and preview email layouts with real-time feedback on content length and best practices. It extends the functionality of the existing landing page builder while focusing specifically on email design constraints and guidelines.

## Core Purpose
- Provide writers with a visual way to design email layouts
- Offer real-time feedback on content length and best practices
- Enable simple export options (JSON and Google Docs)
- Maintain brand consistency with VisionPoint Marketing's design system

## Key Features

### 1. Email-Specific Viewport Controls
- Desktop View: 600px (email-safe maximum width)
- Tablet View: 480px (standard email breakpoint)
- Mobile View: 320px (minimum supported width)
- Real-time preview of how content adapts across devices

### 2. Content Sections

#### Hero Sections
- **Single Column Hero**
  - Headline (40-50 characters)
  - Subhead (80-100 characters)
  - Optional eyebrow text
  - Primary CTA button
  
- **Split Hero**
  - Text and image in balanced layout
  - Reversible layout direction
  - Mobile-optimized stacking
  
- **Text-Only Hero**
  - Optimized for preview text cutoff
  - High-impact typography
  - Centered layout

#### Content Blocks
- **Single Column Content**
  - 250-300 characters optimal length
  - Clear hierarchy
  - Optional CTA button
  
- **Two Column Content**
  - 150-200 characters per column
  - Balanced layout
  - Mobile-responsive stacking
  
- **Bulleted List**
  - 3-5 items recommended
  - 30-40 characters per item
  - Clear formatting

#### Product/Feature Sections
- **Single Product Feature**
  - Image + 150 character description
  - Product name and price
  - Clear CTA button
  
- **Product Grid**
  - Two-column responsive layout
  - 100 characters per product
  - Consistent card design
  
- **Feature List**
  - Icon + 50 characters per feature
  - Three feature maximum
  - Clear visual hierarchy

#### Social Proof
- **Testimonial**
  - 100-150 character quote
  - Attribution with name/role
  - Optional photo
  
- **Metrics Block**
  - Maximum 3 statistics
  - 15-20 characters per label
  - Responsive grid layout
  
- **Logo Bar**
  - Responsive grid
  - Mobile-optimized spacing
  - Optional heading

#### CTA Sections
- **Primary CTA**
  - High contrast design
  - 2-5 word button text
  - Clear action focus
  
- **Secondary CTA**
  - Inline text + button
  - 2-3 word button text
  - Subtle styling
  
- **Button Group**
  - Mixed primary/secondary styles
  - Mobile-optimized stacking
  - Consistent spacing

#### Footer Components
- **Standard Footer**
  - Social media links
  - Contact information
  - Required unsubscribe link
  
- **Extended Footer**
  - Multi-column link layout
  - Social media icons
  - Collapsible on mobile
  
- **Minimal Footer**
  - Copyright text
  - Required legal links
  - Single-line design

## User Workflow
1. Select viewport size for design
2. Add sections from component library
3. Edit content with real-time feedback
4. Preview across device sizes
5. Export content for review/implementation

## Design Constraints
- Maximum width: 600px
- Table-based layouts for email clients
- Limited web font support
- Dark mode compatibility
- Email-safe CSS properties

## Brand Integration

  - Dark Navy: #1A365D
  - Light Gray: #F7FAFC
  - Text Dark: #1A202C

- Standardized spacing

## Export Formats
1. **JSON Export**
   - Complete template data
   - Section configurations
   - Content and metadata
   
2. **Google Docs Export**

   - Section headers
   - Content guidelines

2. Stricter character limits

4. No form builder integration

6. Email-specific content rules

8. Email client compatibility focus
